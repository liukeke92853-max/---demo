渠道达人审核流转增量 PRD

渠道达人通用小程序 · 2026-11-18

环节改造规则
业管待审核渠道达人提交初步审核信息后进入待审核；审核通过后进入 IP 审核。
业管 IP 审核渠道达人进入 IP 审核即为待审核，不出现待提交中间状态；IP 审核通过后进入待绑定，承接 MCN 机构绑定。
达人合作进度业管待审核及 IP 审核的待审核阶段统一显示待审核；IP 审核通过后显示待绑定并进入机构绑定流程。

达人端申请与审核

申请提交前必须单选一个具体合作 IP，移除无意向选项。从广场申请时带入所选 IP，直接打开申请表时不默认代选；未选择时提交提示“请选择一个合作达人”，停留原页，不创建申请、不进入审核。搜索无结果时仅展示空态，不提供跳过 IP 的申请入口。提交后展示的 IP 只读，移除修改 IP 的入口及交互。渠道版申请和后续授权各环节移除客服入口、客服二维码及相关引导；其余页面信息沿用现有切片业务。IP 审核异常后的具体处理方式待业务确认。

验收

渠道达人提交后进入待审核，初审通过后 IP 审核直接待审核；两次审核期间达人均看到待审核，通过后看到待绑定。平台达人现有流程保持原样。

此处描述正常通过路径；驳回与异常处理沿现有业务规则，具体适配待核实。
